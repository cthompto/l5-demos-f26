## Introduction
The examples housed here are saved as .lua files. To run the code you need to download and install the necessary L5 resources which can be found here:

<https://github.com/L5lua/L5>

## Navigating This Repository
The root of this repository (root meaning the first or top-most directory in a file system) contains the an <code>L5.lua</code> and a <code>main.lua</code> file. These are required for running examples. Throughout the semester, the <code>main.lua</code> file in the root folder will change as I am using this repository as an active workspace for developing class resources. 

The "demos" folder will house the code I create for in class demos and other requested examples/demos.

## Reading The Code
When viewing code, remember that <code>--</code> makes a line a comment. A comment is ignored by the computer and is meant to be read by humans. Comments are used to explain the code or communicate important details about it. A comment might look like:

~~~
-- function to set up the canvas
function setup()
    size(600,400)
end()
~~~

In the above, "function to set up the canvas" is a comment.

## Running Examples
The easiest way to run examples is to copy the example code and paste it into your own <code>main.lua</code> file. Remember that you must have the required L5 resources in order to run the examples.
